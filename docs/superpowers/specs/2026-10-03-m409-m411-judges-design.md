## 二、三条判据的设计

### M409｜配对长锚，不是裸 `v-model` 锚

- 本体：`frontend/src/views/ResultView.vue:275`（`<select v-model="store.resultSort" @change="changeSort" …>`）
  与 `:280`（`<input v-model="store.resultExt" @change="changeExt" …>`）。两个处理器在 `:99`／`:100`，
  都是 `store.loadResultPage(false)` 的一行包装。两个字段在
  `frontend/src/stores/scan.ts:1190` 一起导出 ⇒ **互换绑定对象在类型上完全合法**（§6.80 的改坏读数：前端 236 rc=0 且 typecheck rc=0）。
- ★ **不能只锚 `v-model="store.resultSort"`**：`wiring()` 是全文件 `grep -qF`（无行锚、无上下文），
  把两个控件的绑定**互换**之后，那串仍然在这个文件里（只是挪到了 `<input>` 上）⇒ 裸锚**照样假绿**。
  这正是 R4-4 在 M80 那条锚上实测抓到的形状（§6.80 七·3 引的 §30.13 负控制）。
- 修法：**锚"绑定 + 变更处理器"这一对**，因为互换会把整对一起搬走：
  ```
  wiring 'src/views/ResultView.vue' 'v-model="store.resultSort" @change="changeSort"' '' \
    '排序下拉绑 store.resultSort 且挂 changeSort（M409：绑回局部 ref 或两控件互换都不留痕迹）'
  wiring 'src/views/ResultView.vue' 'v-model="store.resultExt" @change="changeExt"' '' \
    '扩展名过滤框绑 store.resultExt 且挂 changeExt（M409 同形）'
  ```
  现读：两条串各**恰出现 1 次**（`grep -cF` = 1／1）。
- ★ `.vue` 导入不了 `node --test` ⇒ 只能走接线锚，这是 M116／M118 定下的先例，**不得称行为级红**。

### M410｜六档表驱动，两层各一枚

- 引擎腿本体：`internal/dedup/pipeline.go:384-391`（`threads := cfg.Threads` 起，`<1` 走 `autoThreads`、`>MaxThreads` 钳到 64），
  常量在 `:573`。钳后值经 `:393 workers := threads` 流进 `scanRun{workers:}`（`pipeline_stages.go:44`），
  再进 `scanner.WalkWithGate(…, s.workers, …)` 与两处 `runWorkers(s.ctx, s.workers, …)`。
- ★ **本批唯一的实现面改动 = 把这三行归一抽成纯函数**（详见「四」的偏差登记）：
  ```go
  func normalizeThreads(n int, roots []string) int {   // 语句逐字搬自 Scan，行为零变化
      if n < 1 { return autoThreads(roots) }
      if n > MaxThreads { return MaxThreads }
      return n
  }
  ```
  `Scan` 内改成 `threads := normalizeThreads(cfg.Threads, cfg.Roots)`。抽的理由：钳后值是 `Scan` 的**局部变量**，
  `scanRun` 实例不外露、`history` 存的是**请求值**（`internal/history/scan.go:108` 写 `cfg.Threads`）⇒
  不动实现就没有任何通道能观察这一档。备选（跑一趟真扫描采样 `runtime.NumGoroutine()` 峰值）已否决：
  夹具阶段在空目录上几微秒就收，峰值**可能采不到** ⇒ 变异不一定红 ⇒ 不满足"改坏必红"。
- 设置腿本体：`app_settings.go:88-91`（`<0 → 0`、`>dedup.MaxThreads → 64`），返回值直接可读，**不需要任何提取**。
- 判据形状（两包各一枚表驱动，同一张六档表）：
  ```
  {0 自动} {1 1} {64 64} {65 64} {10000 64} {-1 自动}
  ```
  断言三件：① 逐档等于期望值；② 生效值恒 `∈ [1..MaxThreads]`（自动腿按 `autoThreads` 实际值比）；
  ③ `0` 与 `-1` 落进**同一档**（都走自动腿，钉住"负数不是报错也不是钳到 1"）。
- 文件：`internal/dedup/pipeline_threads_test.go`（新）、根包并入 `app_m409_m411_test.go` 之外的
  `app_m410_m411_test.go`（新，两腿合一文件：`TestSaveSettingsThreadsClamp` ＋ `TestOperationIDsAreUnique`）。
  ★ 命名照本仓 `app_<号>_<主题>_test.go` 惯例。

### M411｜三腿，全部不吃挂钟

- 本体：`app_ops.go:148`（`ops-<150405>-<taskSeq>`，`taskSeq` 见 `app.go:292`，出口 `:280`）。
  taskID 半边已有判据（`app_p3_test.go:91 TestTaskIDsAreUnique`），opID 半边零。
- 夹具照 `newOperableApp`（`app_p0_p1_test.go:114`）+ `assertIdleAppAcceptsOps` 那条前提自检的路子：
  连发三次 `ExecuteOperation`，每两次之间 `a.wg.Wait()` 等收尾（在途标志复位后才能受理下一次）。
- 三腿与各自的变异对应：
  1. **互异**：三次返回串两两不等 ⇒ 抓"序号写死／不递增"（单靠这一腿抓不住，见下）。
  2. **形态**：必须匹配 `ops-<6 位数字>-<数字>`（`strings.Count(id,"-")==2` ＋ 两段各自 `strconv.Atoi` 成功）
     ⇒ 这一腿是**去掉 `-%d` 退回纯时间戳**那个变异的确定性判据：改坏后只剩两段，与挂钟落在哪一秒无关，**必红**。
  3. **序号严格递增**：第三段的整数值后一次 > 前一次 ⇒ 抓"`taskSeq.Add(1)` 退化成常量 1"
     （那种改坏下，若三次恰好跨秒，第 1 腿会漏；第 3 腿仍必红）。
- ★ 为什么不用 `TestTaskIDsAreUnique` 的"只断言互异"形状：taskID 那枚的挂钟串带日期（`20060102-150405`），
  opID 只带时分秒，同秒两次必同串 ⇒ 互异性单独一条会随**运气**红或绿。三腿合起来才是确定性判据。
- 不动 `app_ops.go`；`undoID`（`:336`／`:471`）同形但**不在本批断言面**（§6.80 登记的缺陷只点名 opID，
  越界断言要给 §6.81 添没登记的判据 ⇒ 留给下一批或就地加行，不顺手扩面）。

## 四、与 §6.80 承诺的偏差（一处，就地登记）

§6.80 五 的 M410 修法写的是「★ 只加判据，不动实现」。本批**动了一处实现形**：
把 `Scan` 里的三行归一抽成 `normalizeThreads`（语句逐字、无行为变化、无新语义、无新常量）。

- 为什么必须动：见「二 · M410」——钳后值是局部变量，不改实现就没有观察通道；而"没有观察通道的判据"等于
  交回一条恒绿的空锚，正是 §6.80 要销的那个缺陷本身。
- 先例：M341 把阶段体整体搬进 `pipeline_stages.go` 时明写「**语句逐字未动**」；
  第七批口径 3「打不通的夹具降级为独立前提自检，**另开测试接缝**（`evictFn`）」。
- 因此本批的准确表述是：**判定逻辑零改动，实现的文件形状为可观察性做了一处等价提取**。
  这句必须进 §6.81 正文，不许写成"零产品代码变更"。

## 五、边界

1. **前端腿只算接线锚**，不得称行为级红（M116／M118 先例）；`.vue` 进不了 `node --test`。
2. **不改任何既有断言**、不改 `--fast` 门禁的行清单；新增锚只让自报接线数 +2（读数里点名前后两值）。
3. **本机是 darwin**：V-c／V-d 的交叉腿（`GOOS=linux/windows go vet`）只证"参编干净"，不证行为。
4. **注释不是判据**：`pipeline.go:388-390` 那段 P2 注释随提取一起进新函数，注释本身不计入判据。
5. 变异期间任一包 baseline 转红 ⇒ 立刻停批回滚，不带红做变异。
6. **本批不占号也不销号外的号**；M409／M410／M411 在 §6.81 销格，下一自由号仍是 **M412**。
