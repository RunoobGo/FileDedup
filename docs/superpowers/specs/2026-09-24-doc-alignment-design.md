## 2. 改法（哪些就地改、哪些一字不改）

1. **§3.2 的表内值就地改 + 打「★ 第十二次核对真读数」标记**，与既有惯例同形（`ops` 行里就写着
   "⇒ 264 → 272，★ 第十次核对真读数"）。表下的** dated 追记段一字不改**——第十一次那两段
   （`792`、`740/745/752`、`789e4d4` 的 worktree、M193 共享树污染）是**登记时刻的真值**，
   改它们等于毁掉当时的取证现场。新追记只往表尾追加。
2. **§4.1 / §4.3 / §5 / §7 / README 属"当前状态描述"，不是历史划账** ⇒ 直接改成真值，
   并各带一句日期化括注说明改前的旧说法是什么（照 §6.9.12 与 M125 的姿势：写明原句，
   否则下一轮原样再报）。
3. **D-5 只挪数字、不改成"锚点命令"**：§5 那两格是表格里的短引用，写命令会把表撑坏；
   但按 M150 的教训在 §5 表头加一句"步骤号随 §4.1 那张 11 步表，§4.1 增删步骤时要回来重数"，
   把复数责任写明。
4. **约束 (1) 仍然生效**：登记表既有行一字不改写；§6.27/§6.36/§6.37 里那些"792""141""136 行"
   是各批当日读数，**一格不碰**。
