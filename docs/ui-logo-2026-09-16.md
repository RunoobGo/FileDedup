# FileDedup Logo 重设计

- 日期：2026-09-16
- 参考来源：用户提供图（两页叠放文档 + 正面指纹 + 折角，AI 生成）
- 原状：`build/appicon.png` 是一张 132KB 的 PNG 唯一来源（不可编辑）；侧边栏品牌区只是 `FD` 两个字母的占位；无 favicon

## 一、母题提炼

从参考图取「**文档 + 指纹**」：指纹即内容哈希，是文件去重最直白的隐喻；叠放的两页呼应"对比"。**弃掉**的要素：右下角印章（含无关文字）、纸质噪点、水印。参考图不直接作为素材使用 —— 全部几何重新矢量化，Python 生成器手算路径。

## 二、三处落点

| 位置 | 文件 | 说明 |
|---|---|---|
| 应用内标记 | `frontend/src/components/Logo.vue` | 内联 SVG，`currentColor` + `<mask>` 遮挡，替换侧边栏 `FD` 文字 |
| 应用图标 | `build/appicon.svg`（源）→ `build/appicon.png`（1024 产物） | Wails 用 PNG 生成各平台图标；SVG 入库作为可编辑真相来源 |
| favicon | `frontend/public/favicon.svg` | 同母题单色版（墨色 `#201A17`，不能用 `currentColor` —— 独立文件没有 CSS 上下文） |

## 三、实测结论（改参数前先看）

以下全部来自 1:1 实渲染对照图（非目测猜测），生成器见第六节：

1. **`<mask>` 挂载点**：掩膜必须挂在**不带 transform** 的外层 `<g>` 上。掩膜内容是在"引用它的元素自身坐标系"里解释的 —— 被遮元素带 transform 时挡片会被一起变换，症状是后一页整页消失。第一版就栽在这里。
2. **环距 vs 笔画**：折线能否分辨只由「环距 ≥ 笔画宽 × ~1.6」决定。48 网格下环距 2.6 / 笔画 1.65 时，40px 起环间可分、44px 清楚、**32px 及以下必糊**（任何环数都救不回来，这是像素密度问题不是参数问题）。所以 Logo.vue 注释里写明 `size` 不要低于 32；更小尺寸应换无指纹简化版。
3. **缺口半角要由内向外递减**（48° → 16°）：内环缺口过大会读成拱形/彩虹。第一版内环缺口半角 56° 等于挖掉 184°，指纹感尽失。
4. **应用图标选 5 环**：128/256 读作指纹，64px 仍是可辨螺旋，32px 从容退化为"文档+朱砂印"。8 环在 256px 像靶环，3 环太空。
5. **侧边栏定 44px**：Retina 下等于 88 物理像素，观感等同 64px 那档。

## 四、几何参数（最终值）

- 画布：应用内 48 网格；图标 1024 画布、安全边距 92、圆角半径按 macOS 大图标（约 22.37%）
- 文档页：21×26.5，圆角 1.6，折角 5.2
- 叠放：后页 `translate(-6.4,-5.6) rotate(-9°)`，前页 `translate(1.4,1.2) rotate(4°)`，前页外扩描边 5.0 作为挡片挖出间隙
- 指纹（应用内 / B-3ring 变体）：椭圆环 squash 1.14，3 环半径 2.6/5.2/7.8 + 核心圈 1.30，缺口半角 48/26/16/34°，笔画 1.65
- 指纹（应用图标 / 5 环）：半径 1.15~8.15 步进 1.0，缺口半角 58→13 递减，笔画 1.05
- 图标配色：奶油底 `#FAF6EC`（PNG 光栅化必须带不透明底，透明底在 Windows .ico 上出问题）、墨线 `#201A17`、朱砂 `#BE3A31`

## 五、验证记录

- 侧边栏真机渲染（Vite 5199，1180×780）：44×44 正确；8 条可见路径 stroke 全部等于 `getComputedStyle(svg).color`（0 处不一致）；掩膜内 2 条 path 黑色属设计使然；亮/暗主题截图各一
- 对比度：标记用色即导航图标用色（`--primary-ink`/`--primary`），沿用全站对比度回归结论（0 失败）；非文本图形元素要求 3:1，亮色 6.70:1 / 暗色更高
- `vite build` 通过（CSS 22.63kB / JS 125.98kB，favicon 进入 `dist/`）
- `wails build` 通过；产物 `iconfile.icns`（106KB）经 `sips` 导出核对为新 logo
- 旧 appicon 132KB → 新 52KB

## 六、复现步骤

生成器与渲染脚本在 `/tmp/fd-logo/`（临时目录，重建需按下述参数重写；核心几何逻辑已固化进 `Logo.vue` 注释与本文档）：

```
gen.py       # 产出 logo-compact.svg / appicon.svg / var-*.svg（四变体对照）
variants.mjs # 四变体 × 实际尺寸 1:1 对照图
ladder.mjs   # 应用图标 16~256 尺寸阶梯对照图
emit.mjs     # appicon.svg→build/、光栅化 PNG、favicon
```

光栅化用 `@resvg/resvg-js`（本机无 rsvg/cairo/ImageMagick），安装在
`~/.workbuddy/binaries/node/workspace/`（隔离目录），以软链 `node_modules` 方式引用
（ESM 不认 `NODE_PATH`）。
